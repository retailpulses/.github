# Engineering — 中央工程入口

这里维护跨仓库共用的工程原则、标准与模板索引；产品专属 TRD、架构、运行手册保留在产品仓库。

## 目录约定

- `principles/`：工程原则（MVP Baseline、简洁性、可诊断性）。
- `standards/`：已确认的共用标准；应具体、可验证，不添加模糊审批门槛。
- `templates/`：供产品仓库引用的轻量模板。

**P0 仅建立目录导航。** 当前生效的 Governance 政策、可复用 Workflow、安装器及工程标准模板仍由 [rp-governance-kit](https://github.com/retailpulses/rp-governance-kit) 维护，迁移按 [#11](https://github.com/retailpulses/.github/issues/11) 进行。未迁入或批准的内容不得在这里自称已生效。

产品级工程说明参见各仓库 README 与 `docs/`。不要在中央维护第二份产品架构。
