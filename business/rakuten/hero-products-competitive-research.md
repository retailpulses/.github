# 楽天市場 Hero Products 同款竞品研究（2026-11-14）

状态：RESEARCH / PARTIAL，不是定价政策或采购决策。研究对象来自 [Mercari Hero 清单](../mercari/merchandising/hero-products.md)，其中 25 个 SPU1 是预备候选，尚未完成全部 25 个的逐项竞品审计。

## 目的与口径

- 从 Mercari 跨店销售证据寻找楽天市場潜在主推商品；按 Giga Item Code/SPU1 搜索直接同款，再补充类别竞品。
- **同 Item Code 是强相关匹配证据，但需核实颜色、套装、规格、运费、库存和交货条件，才能称作完全相同的购买选择。**
- 公开搜索索引的报价/优惠可能过期；商品页面上的“其他推荐商品价格”不能作为当前主商品价格；分规格的“起价”不能和我们的成交均价直接比较。
- 本文观察与建议分开。竞争对手的销量、GMV、广告投资回报未验证，不因评价数高就推定其销量或利润高。

## 首轮执行建议（待验证）

1. **优先试销：** N509P277758、N515P401211、N508P301428；根据 Giga 实时供货、Rakuten 现有商品、履约成本、售后风险和贡献利润排序；Hero ≠ 必然高利润。
2. **商品页结构：** 搜索词覆盖的日文标题 → 首图清晰传达型号/使用场景 → 5–8 张功能与尺寸图片 → 材料/包含物/配送包裹 → 安装指导/视频 → 保修/退换政策。图片数量为内部测试建议，非平台硬性规则。
3. **评价驱动优化：** 每个 SPU 摘取竞争对手好评与差评，形成购前 FAQ；大件物置与展示柜优先消除安装预期差距；不得借用他店评价、虚构用户证言。
4. **价格对照必须完整：** 同变体 SKU、公开最终商品价、优惠券条件、积分、运费、大件附加费、配送日、是否安装、采集时间；输入 Giga Effective TCOGS 和楽天平台费后再测算贡献利润。
5. **促销：** Hero 不默认降价；与 Super DEAL / スーパーSALE / お買い物マラソン分别做定价与贡献利润模拟，先检查是否有商品活动限制。展示的 5%–15% 优惠券并不证明商品盈利或活动有效。
6. **Listing 架构：** Rakuten 页面可集中尺寸/颜色选项；Mercari 公司现行单 Listing 单 SKU 策略不变。商品/SPU 作为跨渠道研究键，Offer 和 Listing 作为渠道特有对象。
7. **渠道目标：** 作为 Rakuten 2027Q1 月销 ¥2,000,000 目标的备选商品池，不能未经库存、售价、毛利和流量验证就推算其收入贡献。
