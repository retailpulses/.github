# Mercari Shops 商品グループ管理参考

**Owner:** リテルパルス合同会社 / Mercari Operations  
**Scope:** 全店；Shop4 优先  
**官方资料核对日:** 2026-11-18 JST  
**性质:** 操作参考；记录本身不执行线上修改。

## 1. 官方来源与边界

- [商品グループ管理機能](https://support.mercari-shops.com/hc/ja/articles/39467798476569)：管理画面操作、法人/Web 限制、三级类目范围、每组最多 10 个商品。
- [商品グループの一括登録・更新](https://support.mercari-shops.com/hc/ja/articles/42646579459993)：专用 CSV、字段及四类操作。
- [普通商品 UPDATE CSV](https://support.mercari-shops.com/hc/ja/articles/60017371839513)：其中分组字段仅供参考，不能借此创建、修改或移除分组。
- [官方 CSV 样例（Mac）](https://guide.mercari-shops-static.com/product_group_import_template_sample.csv)。本次核对了指南字段，未验证样例原始字节；执行时从目标店铺下载当前模板，核对完整表头、顺序和编码。

商品グループ连接多个独立 listing，供买家在详情页切换；不合并商品ID、价格、库存或订单。组内必须属于所选第三级类目配下，不要求叶子类目完全一致。

## 2. CSV 字段

每行描述一个分组。字段如下；实际表头以当前专用模板为准。

| 字段 | 含义 |
|---|---|
| 商品グループ名 | 内部管理名称 |
| 商品カテゴリID | 分组范围的类目ID；不要直接套用商品叶子ID |
| 商品グループID | 未使用的ID创建新组；现有ID更新对应组 |
| 商品画面用タイトル | 买家可见的选择轴，如「カラー」 |
| 商品1_ID ～ 商品10_ID | Mercari 商品ID，按展示顺序排列 |
| 商品1_省略名 ～ 商品10_省略名 | 对应商品的买家可见规格标签 |

内部 Item Code / SPU1 不能替代商品ID。管理用名称、ID不展示给买家；规格标签应使用准确日文，不放内部代码。

## 3. 创建、更新、解除与删除

| 目标 | 方法 | 输入和结果 |
|---|---|---|
| 创建有商品的新组 | 专用 CSV | 新分组ID、组信息、商品ID与标签 |
| 只创建空组 | 专用 CSV | 新分组ID及组信息；所有商品ID与标签留空 |
| 更新组信息、商品或顺序 | 专用 CSV | 现有分组ID；提交预期的组信息和完整成员列表 |
| 清空该组全部商品关联 | 专用 CSV | 保留现有分组ID和组信息；所有商品ID与标签留空。保留空组，不等于删除组 |
| 移除部分商品 | 管理画面编辑；或完整成员列表更新 | 保留其余成员。CSV 对省略成员的处理应先小批验证，不能假定为追加或局部 patch |
| 删除整个分组 | 管理画面 | 「商品」→「商品グループの管理」→选择目标组→「商品グループを削除する」 |

官方 CSV 指南未提供“删除分组对象”的专用控制字段。不要编造 delete 标志，也不要用普通商品 CSV 的商品删除状态替代解除关联。

### 创建流程

1. 确认目标店铺，导出现有商品与分组资料。
2. 从「商品」→「CSV一括機能」→「商品グループ一括登録・更新」下载模板。
3. 填写新ID、类目、组信息和最多10个商品，上传并核对预览。
4. 执行一括登録・変更，等待历史显示「変更完了」，随后回读核对。

也可在「商品グループの管理」中选择「商品グループを登録」，填写组信息、添加商品及标签后保存。

### 更新流程

沿用现有分组ID，先保存旧状态，再准备完整目标状态；上传预览后核对成员、标签和顺序。管理画面同样支持选择组后「商品グループを変更する」。不要因改名而新建ID，也不要假定空白字段表示不变。

### 移除与重组流程

先区分“移除一个成员”“清空所有关联”“删除整个组”。迁移时先从旧组解除，回读确认，再加入目标组；不要假定跨组自动搬迁。若需改商品分类，先解除关联、单独执行分类修改、重新导出验证，再按正确类目建组；该顺序是公司恢复性操作建议，不把尚未核实的分类锁定条件写成平台事实。

## 4. 公司执行与恢复约定

- 保留变更前的完整组配置及成员ID、标签、顺序，形成 before/after 差异。
- 先小批验证创建、更新、部分移除的实际语义；普通商品 CSV 的数量上限不套用于分组 CSV。
- 分组完成必须同时核对导出状态和买家页面；上传受理不代表成功。
- 失败或结果不明时，先回读再重试；保留错误结果及批次记录。
- 回滚以旧组配置恢复关联；已删除组能否复用原ID须验证，不保证恢复原对象。
- 不得在分组操作中顺带改价格、库存、商品ID或删除 listing。
