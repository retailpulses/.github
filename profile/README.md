# Retailpulses

Retailpulses GK 在日本开展跨平台电商运营与软件开发，构建支持 Mercari、Rakuten、Amazon Japan 等渠道的运营工具和内部工程能力。

## Engineering Registry

从 [Retailpulses Engineering Registry](https://github.com/retailpulses/.github) 查找组织级工程标准、基础设施与 Runtime 清单、仓库目录和 Foundational API References。

## Product & engineering repositories

- [commerce-ops](https://github.com/retailpulses/commerce-ops) — 电商运营产品与相关工作流
- [store-ops](https://github.com/retailpulses/store-ops) — Marketplace Store Operations
- [CatalogSync](https://github.com/retailpulses/CatalogSync) — Catalog 数据同步
- [commerce-lab](https://github.com/retailpulses/commerce-lab) — 本地分析、数据工作流与实验工具
- [retailpulses-tool-services](https://github.com/retailpulses/retailpulses-tool-services) — MCP、CLI 与工具服务
- [RPagentOS](https://github.com/retailpulses/RPagentOS) — Agent 平台相关代码
- [inbox](https://github.com/retailpulses/inbox) — 跨系统工作、业务组合协调与 Sponsor 决策

其他仓库及其核实范围见 [Repository Registry](https://github.com/retailpulses/.github/blob/main/registry/README.md)。该索引不替代产品仓库中的架构、实现或运行说明。
